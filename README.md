## About this entry

The line is advice someone actually gave, which is exactly what the
bounty asks for. It comes from a grandmother, so the advice arrives
already lived-in, two rules learned the hard way rather than
invented for the contest. The first rule warns against anyone who
says "trust me", and the second warns against anyone who opens with
"this is not about the money". Both rules are about the same thing,
the words people use right before they do the thing they deny, and
the laugh comes from recognising both phrases at once. The line is
a single sentence, it needs no explanation, and it stays well inside
the two hundred character cap. The program holds the line, checks it
against that cap, and writes it to /output/entry.txt exactly as the
bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
